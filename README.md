# 🌱 Smart Greenhouse IoT System

Інтелектуальна система моніторингу та керування мікрокліматом теплиці на базі ESP32, Node.js та MongoDB.

## 🚀 Основні можливості
* **Моніторинг у реальному часі:** Температура, вологість повітря, вологість ґрунту та освітленість.
* **Розумне провітрювання:** Автоматичне керування сервоприводом за температурою або ручний режим через Web-інтерфейс.
* **Система алертов:** Візуальне сповіщення на дашборді, якщо показники виходять за межі норми.
* **Аналітика:** Графіки середніх значень за кожну хвилину останньої години.
* **Звітність:** Експорт зібраних даних у формат CSV (Excel-сумісний).

## 🛠 Технологічний стек
* **Hardware:** ESP32, BME280, BH1750, Capacitive Soil Moisture Sensor, MG90S Servo.
* **Backend:** Node.js, Express, MongoDB Atlas (Mongoose).
* **Frontend:** HTML5, CSS3 (Modern UI), JavaScript (Async/Fetch), Chart.js.

## 📂 Структура проєкту
* `server.js` — серверний код та API.
* `index.html` — головна панель керування.
* `history.html` — сторінка графіків та звітів.
* `style.css` — спільні стилі інтерфейсу.
* `smart_greenhouse.ino` — прошивка для ESP32.
